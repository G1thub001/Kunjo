# AuraGems - Luxury Jewelry Store

A sleek, responsive, and modern e-commerce web application designed to showcase fine jewelry, gemstones, and handcrafted accessories.

---

## 💎 Features

* **Showcase Collections**: Dedicated visual sections for rings, necklaces, bracelets, and custom luxury pieces.
* **Interactive Product Carousels**: Smooth product sliders using `Owl Carousel` and `Slick` to display featured items and featured collections.
* **Responsive E-Commerce Layout**: Optimized across desktop, tablet, and mobile displays using custom CSS media queries and Bootstrap.
* **Smooth Micro-Interactions**: Dynamic animations (`animate.min.css`) and custom interactive navigation controls.
* **Rich Iconography**: Custom icons and FontAwesome integration for intuitive shopping controls (cart, wishlist, search).

---

## 🛠️ Built With

* **HTML5 & CSS3**: Custom responsive styling, grid layouts, and typography.
* **JavaScript & jQuery**: Interactive product sliders, modal previews, and navigation logic.
* **Bootstrap**: Layout scaffolding and mobile responsiveness.
* **FontAwesome**: UI iconography and store badges.
* **Owl Carousel & Slick**: Dynamic product and banner carousels.
